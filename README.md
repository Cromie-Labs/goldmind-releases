# Goldmind sync app: downloads

Installers for the Goldmind sync app, the free desktop companion to the Goldmind World of Warcraft addon.

**Get it at [goldmind.gg/download](https://goldmind.gg/download).** Each [release](https://github.com/Cromie-Labs/goldmind-releases/releases) carries the Mac, Windows and Linux installers and the signed update manifest the app checks for updates.

This repo holds release files only; the source is private. Support: support@goldmind.gg or [Discord](https://discord.gg/KFyRhpdHA).
